# AI Fitness Assistant

## Overview

AI Fitness Assistant is a Python-based web application that helps users improve their fitness through personalized diet recommendations, exercise suggestions, posture detection, and an AI-powered fitness chatbot.

## Features

### Personalized Diet Recommendation

* Suggests diet plans based on fitness goals
* Uses nutrition data for recommendations

### Exercise Recommendation

* Recommends exercises by body part
* Beginner-friendly workout suggestions

### Posture Detection

* Real-time posture monitoring using MediaPipe and OpenCV
* Helps users maintain proper exercise form

### AI Fitness Chat Assistant

* Answers fitness-related questions
* Provides workout and nutrition guidance

## Technologies Used

* Python
* Flask / Streamlit
* Pandas
* NumPy
* OpenCV
* MediaPipe
* HTML
* CSS
